## ADDED Requirements

### Requirement: Подробности шага расшифровывают, что шаг получил
Для выбранного исполнения шага монитор SHALL первым показывать человекочитаемый блок «Что получил шаг», собранный только из сохранённого Run: каждый входной порт с происхождением (вход запуска с его значением или результат названного шага с переходом к нему и содержимым артефакта по раскрытию), ответы решений, переданные исполнителю, с названием решения, значением и источником ответа, вопросы шага — runtime-решения, заданные этим исполнением или ожидающие ответа, и вопросы из отчёта исполнителя — с текстом вопроса, вариантами, ответом, основанием ответа, тем, кто и когда ответил, переданные тексты инструкций и контекста с названием, объёмом и полным текстом по раскрытию, а также ожидаемые выходы, вердикты с продолжением в графе, класс эффекта и захватываемые файлы рабочей копии. Существующие разделы и сырые сохранённые данные SHALL оставаться доступны без изменений. Сведение, которого нет в Run, MUST обозначаться как незаписанное, а не выводиться из текущих файлов, профиля или каталога.

#### Scenario: Assisted-шаг получил задачу, ответы и промпт
- **WHEN** пользователь выбирает Attempt assisted-шага, которому переданы вход запуска `task`, результат предыдущего шага, ответы решений и тексты контекста
- **THEN** блок называет происхождение каждого входа, показывает текст задачи, название и значение каждого переданного ответа с его источником и название каждого переданного текста, раскрываемого целиком

#### Scenario: Навык шага задал объявленный вопрос
- **WHEN** Attempt запросил runtime-решение, и на него ответили заранее запечатанным ответом или человек во время Run
- **THEN** блок показывает вопрос с его вариантами, выбранный ответ, кто его дал и когда; вопрос, ещё ждущий ответа, показан как ожидающий

#### Scenario: Агент сам ответил на вопросы навыка
- **WHEN** отчёт исполнителя Attempt перечисляет вопросы с ответами и основаниями
- **THEN** блок показывает каждый вопрос, ответ и основание (решение Run со ссылкой на него, вход шага, инструкции, человек, суждение агента), подписанные как заявление исполнителя; пустой отчёт показан как «исполнитель заявил: вопросов не было»

#### Scenario: Run без отчёта о вопросах
- **WHEN** Attempt записан версией, которая не требовала отчёта о вопросах
- **THEN** блок говорит, что вопросы в этом Run не записывались, и не утверждает, что их не было

#### Scenario: Program-шаг
- **WHEN** выбран Attempt шага, исполняемого программой без сессии агента
- **THEN** блок показывает входы и ожидаемые выходы и прямо говорит, что ответы решений и тексты инструкций такому шагу не передаются

#### Scenario: Run записан до передачи ответов в сессию
- **WHEN** в сохранённом Attempt нет переданных ответов решений
- **THEN** блок обозначает их как не записанные в этом Run и не подставляет ответы из листа решений

### Requirement: Обзор Run показывает входы и решения запуска
Обзор Run SHALL показывать значения входов запуска с источником каждого значения и все записи запечатанного листа предзапусковых решений с названием решения из каталога, значением и источником ответа. Решение, неприменимое к профилю пакета Run, SHALL быть названо неприменимым. Длинное значение SHALL показываться сокращённо с раскрытием полного текста.

#### Scenario: Владелец проверяет, с чем запущен Run
- **WHEN** пользователь открывает Run, запущенный с листом решений
- **THEN** он видит без раскрытия сырых данных, какой профиль и какие ответы действуют, кто или что их дало, и какие значения получили входы запуска
