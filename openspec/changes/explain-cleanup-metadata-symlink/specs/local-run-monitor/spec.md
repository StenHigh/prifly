## ADDED Requirements

### Requirement: Отказ очистки на ссылке называет проблемные метаданные
Если подготовка очистки обнаружила символическую ссылку в общих метаданных authority, монитор SHALL показать код `unsafe_path`, относительный путь ссылки и объяснение причины. Проверка SHALL действовать для адресной и общей очистки и повторяться перед удалением. Отказ MUST NOT удалять Run или следовать ссылке. Перенос тестовых файлов за пределы метаданных SHALL позволять повторить штатный предпросмотр без ослабления защиты.

#### Scenario: Тестовая ссылка мешает удалению завершённого Run
- **WHEN** метаданные `.prifly` содержат тестовую символическую ссылку
- **THEN** подготовка удаления отказывает, указывая эту ссылку, а Run и внешняя цель сохраняются
