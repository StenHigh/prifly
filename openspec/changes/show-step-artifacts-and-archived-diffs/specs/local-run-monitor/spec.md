## MODIFIED Requirements

### Requirement: Подробности показывают переданное задание и сохранённые результаты
Монитор SHALL человекопонятно показывать записанное задание попытки, инструкции и контекст, входы, сведения об исполнителе, полученный кандидат и принятый результат, проверки, выходные артефакты и журнал Pri-Fly. Полные структурированные данные остаются доступны для разбора. Просмотр содержимого артефакта SHALL явно сообщать объём и обрезание предпросмотра. Список файлов SHALL опираться только на сохранённые manifests/evidence и не выдавать текущие изменения рабочей папки за исторический результат шага. Переписка чатов и вызовы инструментов не входят в этот срез.

#### Scenario: Задание выдано, результат не поступил
- **WHEN** Attempt передана внешнему исполнителю
- **THEN** пользователь видит переданное задание и ожидание результата, без утверждения о живом процессе агента

#### Scenario: Список файлов не записан
- **WHEN** сохранённые данные не позволяют установить изменения файлов
- **THEN** интерфейс обозначает сведения как недоступные, а не показывает ложный пустой список

## ADDED Requirements

### Requirement: Артефакты видны в карточке исполнения шага
Монитор SHALL отдельно показать точные входы и принятые выходы выбранной Attempt. Монитор SHALL открыть их содержимое, тип и записанное происхождение. Документы, диапазоны коммитов, merge request и сохранённые diff имеют предметный просмотр. Остальные артефакты сохраняют общий просмотр.

#### Scenario: Один текст, разные ссылки
- **WHEN** входной и выходной снимки содержат одинаковый текст с разными ArtifactRef
- **THEN** монитор сохраняет обе ссылки и показывает совпадение содержимого, если его подтверждают сохранённые хеши

#### Scenario: Рабочее дерево удалено
- **WHEN** оператор открывает сохранённый diff из принятого результата
- **THEN** монитор показывает границы, файлы и сохранённые изменения по ArtifactRef без обращения к Git

#### Scenario: Архив не был записан
- **WHEN** исторический Run содержит диапазон коммитов без сохранённого diff
- **THEN** монитор показывает записанный диапазон и сообщает об отсутствии архива
