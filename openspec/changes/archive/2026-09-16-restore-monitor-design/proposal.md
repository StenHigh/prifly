## Why

Согласованное оформление монитора осталось незакоммиченным в утраченном временном worktree `codex/monitor-design`. Установленный монитор показывает прежний интерфейс без эмблемы и переключателя тем. Восстанавливаем точные правки из истории задачи и сохраняем их в Git.

## What Changes

- Вернуть эмблему и панораму из README, сине-графитовую палитру, плотную типографику и заголовок «Pri-Fly».
- Вернуть выбор светлой, тёмной и системной темы с сохранением предпочтения в браузере.
- Проверить выдачу встроенных ресурсов, темы, навигацию и узкий экран на текущем коде.

## Capabilities

### Modified Capabilities
- `local-run-monitor`: явный выбор темы в дополнение к системной.

## Impact

Только web UI локального монитора и встроенные статические ресурсы. Runtime, данные Run, API чтения и обслуживание хранилищ не меняются.
