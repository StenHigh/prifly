## 1. Дефолты команды в extend.yaml

- [x] 1.1 `extend.yaml` принимает необязательный `model_profiles`: первый
  уровень — хост из известных движку, второй — имя профиля по шаблону
  `^[a-z][a-z0-9-]{1,63}$`, значение — непрозрачная карта строка→строка.
  Отказ на неизвестном хосте, на имени вне шаблона, на нестроковом значении и
  на превышении разумных пределов. Профиль, которого не объявляет ни один шаг,
  **не** отказывается: пакет общий.

- [x] 1.2 Схема редактора `extension-v1` знает блок; справочник расширений
  его описывает, включая то, что значения движок не толкует. Проверка:
  `python3 -B test/e2e/test_examples.py`.

## 2. Переопределение разработчика

- [x] 2.1 `project local set --model-profile HOST NAME key=value` пишет в
  `local.yaml` рядом с путями программ и окружением. Повтор флага добавляет
  ключи одной записи; отдельная запись заменяется целиком.

- [x] 2.2 Отказ, когда хост не известен движку или имя профиля вне шаблона —
  теми же кодами, что и в пакете, чтобы автор видел одно правило.

## 3. Слияние и запечатывание

- [x] 3.1 Слияние **заменой записи целиком**: локальная запись побеждает
  пакетную, частичного смешивания нет. Тест: пакетный
  `{model: opus, effort: high}` и локальный `{effort: medium}` дают ровно
  `{effort: medium}`, а не третье значение, которого никто не писал.

- [x] 3.2 Перевод для выбранного хоста запечатывается при старте, как
  `environment`. Тест: правка `local.yaml` после старта не меняет того, с чем
  идёт уже начатый Run.
