## Why

В Full оператор видит причину, но переход часто открывает целую вкладку. После прямого открытия Attempt на телефоне возврат оставляет дерево исполнения ниже экрана.

Light не даёт наблюдать за двумя выбранными Run на одном экране. При проверке v0.13.93 длинная строка в истории задачи расширила страницу с 390 до 571 px.

## What Changes

- Добавить в наблюдение Full точный переход к вопросу, Attempt или событию, когда записанные данные однозначно определяют цель. При неполных данных назвать доступную область.
- В карточке Run открыть ожидающий вопрос из обзора, показать записанную причину в сведениях нужной Attempt и вернуть фокус к её узлу дерева на телефоне.
- Добавить в Light компактное наблюдение за одним или двумя явно выбранными Run. Сохранить у каждого состояние, известную причину, свежесть и переход в нужную область Full.
- Уложить историю задачи Light в ширину телефона. Сохранить чтение и копирование длинных значений.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `local-run-monitor` — переходы из наблюдения и карточки Run в Full.
- `control-security-ux` — пользовательские правила наблюдения Light и мобильной истории задачи. Проекция `prifly-light` по-прежнему определяется в [действующем change Light](../add-prifly-light-task-board/specs/prifly-light/spec.md).

## Impact

Будущая реализация затрагивает браузерное представление Full и Light, браузерные проверки и действующий справочник оператора. Изменение сохраняет runtime, versioned JSON, сохранённые ответы replay и текущие HTTP endpoints. Переходы остаются в пределах доступного чтения.

Источник требований каждой возможности остаётся прежним по [карте источников](../../SOURCE-OF-TRUTH.md). Разработка и приёмка этого изменения не закрывают открытые released и production gates Light.
