## ADDED Requirements

### Requirement: Ответ на решение package profile доступен шагу
Ответ на объявленное решение с destination `package_profile` MUST быть доступен
шагу тем же чтением, что и остальные объявленные ответы, либо задание MUST явно
называть канал, по которому этот ответ приходит. Инструкция «прочитать
объявленные ответы» MUST NOT терять ответ, который владелец дал.

#### Scenario: Шаг читает объявленные ответы
- **WHEN** шаг получает задание Run, у которого решение о profile отвечено
- **THEN** ответ на profile либо присутствует среди прочитанных ответов, либо
  задание называет отдельный канал, из которого его следует прочесть
