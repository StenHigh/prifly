## Context

См. [proposal.md](proposal.md). Сейчас `activityRows()` перечисляет незавершённые Attempt, готовые StageActivation и ожидания; при пустом списке экран Run всегда пишет «Активная работа и ожидания не записаны». Для терминального `partial` это маскирует границу Run. `MonitorView` уже содержит сохранённое состояние и закреплённые определения; `run explain` и узловые подробности доступны без изменения authority.

## Goals / Non-Goals

**Goals:** компактная, проверяемая сводка терминального состояния и переход к сохранённому основанию частичного итога.

**Non-Goals:** реконструкция невидимой работы хоста, запуск продолжения, интерпретация произвольной схемы проектных артефактов как решения Pri-Fly.

## Decisions

1. Раздел «Сейчас» сначала различает живой и терминальный Run по сохранённому `status`, затем показывает активные строки только для живого. Терминальный экран говорит о завершении именно этого Run; `partial` не приравнивается к `running` или `awaiting_host`. Альтернатива — оставить общий empty-state и добавить tooltip — не устраняет ложного впечатления о паузе.
2. Причина строится из фактического завершающего пути и однозначно относящихся к нему принятых результатов, их summary и ссылок на output artifacts. Показанный текст атрибутируется источнику; проектный `suggested_next` остаётся содержимым артефакта, не управляющим предписанием. Если связь нельзя доказать, показываются известные stage/outcome и «Причина не установлена по записи Run». Альтернатива — взять последний хронологический `needs_revision` — ошибочна для параллельных и вложенных ветвей.
3. Переиспользуются существующий read cut, карточки узлов и просмотр артефактов; новые поля state/API и обратный поиск continuation Run не нужны. Ссылка на иной Run допустима лишь при уже записанной прямой связи, но не является условием этого change.

## Risks / Trade-offs

- Неполная история или сложный вложенный маршрут → безопасный fallback «причина не установлена», без эвристического обвинения шага.
- Summary результата может быть непрозрачным для человека → показывать его как сохранённый текст с источником и доступом к полному результату, не переписывать смысл.
- Слово «продолжение» может обещать автоматический переход → формулировать только границу текущего Run и ссылаться на другой Run лишь при доказанной связи.

## Migration Plan

Только изменение представления монитора. Откат UI не меняет сохранённые Runs. Нормативный source set остаётся `openspec/specs/local-run-monitor/spec.md`; этот delta синхронизируется обычным OpenSpec-процессом.
