# Выпуск Pri-Fly 0.12.3

Патч к 0.12.2, выпущен в том же окне. Обе правки нашла сессия
`prifly-aif-workflows`, прогнав свои ворота и полевое воспроизведение против
выпущенного 0.12.2 — то есть снаружи этого кода, чего его собственные тесты
сделать не могли.

## Замену пакета можно довести до конца

`packageAdmissionGate` требовал, чтобы **каждый** пакет, объявляющий нужный
компонент, оставался разрешимым, вместо «хотя бы один». После штатной замены —
`package remove` старого, импорт нового — прежняя запись всё ещё называет тот
же компонент, и старт отказывал на ней, хотя новый пакет его поставляет.

То есть способ заменить пакет, описанный в отказе `definition_drift` этого же
семейства выпусков, нельзя было довести до конца. На 0.12.1 это не проявлялось
только потому, что раньше срабатывал сам `definition_drift`.

Теперь компоненту нужен один разрешимый поставщик. Отказ, когда его нет, назван
точнее: `no trusted package supplies <id>; <pkg> declared it and is no longer
trusted`. Отзыв остаётся безусловным стопом независимо от других поставщиков —
это запрет, а не вопрос разрешимости.

Дефект старше 0.12.2 и виден только на пройденном целиком пути: он не
воспроизводится ни компиляцией, ни импортом, ни стартом по отдельности.

## Повторный импорт неизменной ревизии — успех, а не отказ

Движок отклонял импорт уже доверенной идентичной ревизии, записывая
`package_present` в квитанцию. До 0.12.2 отклонённая команда выходила нулём,
поэтому отказ был невидим и внешние ворота считали такой импорт успешным; в
0.12.2 он стал видимым и покрасил их.

Возвращать невидимость было бы неверно. Просить состояние, которое уже держится,
— это не отказ: идентичный повторный импорт доверенной ревизии теперь успешен,
запись не меняется, квитанция несёт `{"already_trusted": true}`. Ревизия,
записанная как `removed`, `quarantined` или `revoked`, по-прежнему отвергается,
и отказ называет её статус и то, что импорт её не восстанавливает.

  Идемпотентный импорт не посчитан за новую сборку; пятый запуск проходит

  `{"outcome":"no drift; the upgraded package started a Run"}`. Та же
  последовательность давала `definition_drift` на 0.12.1 и
  `package_not_resolvable` на 0.12.2; путь обновления пройден целиком впервые.

Формы контрактов не двигаются.
