## Context

Attempt хранит точные ссылки на входы. Принятый StepResult хранит точные ссылки на выходы. Pri-Fly хранит содержимое артефактов отдельно от рабочих деревьев.

## Goals / Non-Goals

Дать оператору просмотр артефактов в выбранной попытке. Сохранять текстовые изменения для просмотра без Git. Для старых Run показывать записанные диапазоны и явно обозначать отсутствие архива.

## Decisions

- Монитор читает артефакт через существующий запрос по точной ссылке. Закреплённая схема определяет вид артефакта. Монитор выводит содержимое без выполнения записанного HTML.
- Assisted шаг объявляет встроенную схему `core:schema/git-diff@1.0.0` на выходе `diff`. Если шаг получает `implementation`, он также объявляет `step_diff`.
- Границы общего diff задаёт выход `implementation`. Diff шага начинается с головы входного `implementation`. Равные головы подтверждают пустое сравнение. Если пары совпадают, достаточно общего diff.
- Приём отчёта считывает claim и получает сравнения до записи кандидата. Git работает вне транзакции изменения состояния. Движок сохраняет diff как обычный ArtifactRevision и записывает ссылку в принятом результате.
- Освобождение дерева проверяет архивы принятых результатов. Если получение diff не удалось, исполнитель может повторить отчёт. Для отмены непринятого отчёта действуют существующие правила.

## Risks / Trade-offs

Движок отклоняет отчёт, если сравнение невозможно прочитать или оно превышает предел артефакта. После устранения причины оператор повторяет отчёт без повторного выполнения шага. Снимок содержит текстовые изменения и список файлов. Полный файл требует отдельного снимка.
