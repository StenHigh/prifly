Проверки адресные по затронутым packages. Дорогие ворота один раз на собранном
кандидате. Внешняя проверка на трёх видах захвата — за сессией пакетов.

## 1. Исполнитель видит объявленную привязку

- [x] 1.1 Установлено фактом, где собирается рабочая копия и что в неё попадает;
      привязка шага в этот момент доступна, а не восстанавливается из плана.
      Место: `prepareWorkspace` в `internal/runtime/driver.go`.
- [x] 1.2 Документ несёт привязки того шага, для которого подготовлен: имена
      портов и политику захвата целиком, тем же объектом, что объявлен в шаге.
      Проверка: шаг с `direct_child_tree` показывает вид, путь и точку входа.
- [x] 1.3 Шаг без объявленных привязок документа не получает. Проверка:
      сборка сообщает «не объявлено», файл не пишется.

## 2. Версии контрактов не двигаются

- [x] 2.1 Установлено исполнением, что подъём версии манифеста невозможен:
      строка версии входит в контракты чтения прогона всех поколений, они
      закреплены по хешу, и живой прогон обязан ими читаться. Решение записано
      в design как 3-бис; отменённая правка сохранена в `git stash`.
- [x] 2.2 Ни один опубликованный бандл не сдвинулся. Проверка: `make
      schemas-check` зелёный, 48 бандлов, версии контрактов прежние.

## 3. Неверный ответ соседнего поля

- [x] 3.1 Документ называет путь слота недоступным для записи и называет оба
      отказа, которые исполнитель заработает, последовав ему. Проверка: текст
      содержит `workspace_tree_output_host_supplied` и
      `workspace_tree_capture_conflict`.

## 4. Отказы, которые перестают быть единственным источником

- [x] 4.1 `workspace_tree_output_host_supplied` и
      `workspace_tree_capture_conflict` сохраняют коды и тексты: документ
      сообщает контракт, но не отменяет его проверку.

## 5. Завершение

- [x] 5.1 Документ лежит рядом с манифестом, который он поправляет, а не в
      рабочей копии репозитория. Проверка: сквозной тест на ассистируемом
      заходе читает его из каталога, где лежит `context.json`.
- [x] 5.2 Evidence: `make check` (48 бандлов) и `make e2e` (169 и 75 команд,
      10 кейсов) зелёные на `4ee5a26`; `verify` 34173844354 и `race`
      34173844475 зелёные. Выпущено в 0.12.7.
- [ ] 5.3 Внешняя проверка сессией пакетов на профилях `fast`, `full`, `ultra`:
      содержимое дословно, сверка байт в байт с объявленным в скомпилированном
      шаге, и шаг без захвата. Записать их вывод как есть.
