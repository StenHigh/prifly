# Выпуск Pri-Fly 0.13.39

Тег на `5129f74`. Пять мест, каждое из которых говорило о себе не то, что
есть, и каждое читалось как верное, пока его не посчитали.

## Что стало

- **Отказ проектной поверхности несёт свой код в конверте.** 382 сайта, 105
  разных кодов уходили на провод как `code: "invalid_usage"`, а настоящий код
  лежал внутри предложения, которое читатель должен был разобрать сам.
  `refusal-check` запрещал ровно эту форму для `errors.New` и `fmt.Errorf` и
  никогда не смотрел на `usageError` — поэтому правило держалось везде, кроме
  поверхности с наибольшим числом кодов. Теперь guard читает и `usageError`.
- **Предел чтения истории и бенчмарки** — см. «Что показал перемер» ниже.
- **Preflight ограничен своей группой процессов.** Объявленный таймаут — это
  обещание, что preflight не может держать launch открытым. `CommandContext`
  убивал только запущенную программу: внук держал трубу вывода, и `Run` ждал
  трубу, а не программу. Дедлайн в полсекунды ждал тридцать секунд.
- **Список handoff'ов читает Run один раз.** Было n+1 чтений на n handoff'ов,
  каждое со своим срезом, поэтому список мог разойтись сам с собой.
- **Контракт next-ответа — одна лестница, а не две.** `Next` считал его по
  второй копии: шестнадцать `if` подряд, каждый перезаписывал предыдущий, и
  следом цепочка из четырнадцати `else if` в обратном порядке.

## Что показал перемер

Фикстура обоих бенчмарков `*10MB` подавала команды в режиме `CommandGuarded`,
не создав Run: **applied=0, rejected=1200, runs=0**. База, которую открывали и
сканировали, держала 1200 квитанций отказа, ни одного Run и ни одного события.

Контроль на одной машине (Apple M1, `-benchtime 10x -count=3`):

| | старая фикстура (0 Runs) | настоящие 10 МБ |
|---|---|---|
| `OpenStore` | 10.0–10.8 мс | 17.4–19.3 мс |
| `Verify` (полный скан) | 3.11–3.16 мс | 76.1–86.8 мс |

Старая фикстура воспроизводит архивные 3.2 мс точно, поэтому разница —
фикстура, а не железо. Вывод от 2026-09-04 («открытие упирается не в проверку,
а в установку соединения») на настоящей базе переворачивается: скан в **4.4
раза дороже** открытия. Архивные числа не переписаны — они верны для того, что
тогда измерили.

## Совместимость

**Видимый текст отказа изменился.** Было
`{"code":"invalid_usage","message":"project_execution_not_allowed: use project local set …"}`,
стало
`{"code":"project_execution_not_allowed","message":"use project local set …"}`.
Читатель, матчащий строку `project_…: ` в stderr, сломается; читатель,
матчащий `code`, впервые получает настоящий код. Настоящие ошибки формы
(`--project needs a directory`) остались `invalid_usage`.

`safe_next_actions` для `project_*` без своей записи по-прежнему `["help"]`,
как было у `invalid_usage`. `exitForCode` получил `project_` раньше подстрочных
правил: иначе восемь кодов со словом conflict в имени стали бы классом 3
(«состояние authority не то, что вы предполагали»), хотя это расхождение двух
строк в project.yaml — класс 2. Побочно `project_profile_conflict` и
`project_runner_conflict` перешли с 3 на 2, и это исправление.

Опубликованные контракты не менялись: ни новой state version, ни нового
семейства. 57 бандлов схем сошлись теми же sha256.
