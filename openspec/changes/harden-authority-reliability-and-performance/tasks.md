Порядок фаз — порядок приоритета. Каждая фаза поставляется своей серией
коммитов с зелёным `make ci-check`; фаза не начинается, пока предыдущая не
имеет записанного evidence. Все команды выполняются из явного target worktree
(`git -C`, абсолютные пути). Проверка защищённой истории общая для каждой
задачи: `git diff --name-only -- openspec/changes/archive` пуст, published
bundles и historical evidence не изменены.
