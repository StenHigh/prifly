## ADDED Requirements

### Requirement: Монитор показывает, куда ушло время
Обзор Run SHALL показывать свод времени по категориям с долей каждой и таблицу стадий по убыванию затраченного времени с числом исполнений стадии. Подробности Attempt SHALL показывать его фазы по порядку. Каждая величина SHALL нести признак качества (измерено, оценка, частично, недоступно); неизвестное MUST NOT показываться нулём.

#### Scenario: Оператор ищет, что съело время
- **WHEN** он открывает завершённый Run с повторами review и fix
- **THEN** он видит без раскрытия сырых данных, сколько ушло на работу агента, программы, ожидания и простой, какие стадии заняли больше всего и сколько раз каждая исполнялась
