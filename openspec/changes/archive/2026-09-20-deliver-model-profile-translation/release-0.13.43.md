# Выпуск Pri-Fly 0.13.43

Тег на `0f2c8e7`. Последнее звено профиля модели: проект говорит, что
объявленное имя значит для его хоста, Run это запечатывает, задача доставляет.
Движок по-прежнему **не выбирает** модель и в значения не смотрит.

## Что стало

- **Дефолты команды — `model_profiles` в `extend.yaml`** пакета. Ключ первого
  уровня — хост, **известный сборке**; второго — имя профиля по тому же
  шаблону, что объявляет шаг; значение — непрозрачная карта строк.
- **Переопределение машины — `model_profiles` в `local.yaml`**:
  `project local set --model-profile "HOST NAME key=value"`, повторяемый.
- **Слияние заменой записи целиком.** Пакетный `{model: opus, effort: high}`
  и локальный `{effort: medium}` дают ровно `{effort: medium}`. Покличевое
  слияние родило бы значение, которого не писал ни один файл, и `source`
  описывал бы только его половину.
- **Запечатывание при старте**, как у окружения программ: правка `local.yaml`
  после старта видимо не является частью уже идущего Run.
- **Доставка**: `model_profile_translation` **рядом** с `model_profile` в
  задаче, `{values, source}`, где source — `project_default` или `local`.
  Отсутствие перевода — не отказ.

Значения остаются непрозрачными: `reasoning_effort` у Codex и `effort` у
Claude Code доезжают как написаны, потому что движок не знает, что значит ни
то, ни другое.

## Правило о хостах: моя ошибка, пойманная до сборки

Я собирался проверять ключ первого уровня по хостам, **объявленным проектом**.
Сессия пакета показала, что это ломает ровно тот сценарий, ради которого блок
нужен: пакет общий и обязан нести дефолты для всех трёх хостов, а проект
объявляет один-два — значит `workflows add`/`compile` отказал бы каждому
проекту без `codex-app`.

Проверка идёт по хостам, известным сборке. Опечатка ловится, запись для
хоста, на котором здесь никто не стартует, просто не применяется.
Предупреждения на неё тоже нет: это нормальная форма общего пакета, а не
подозрительная, и предупреждение приучало бы его игнорировать.

Их настоящий блок — три хоста, девять записей — лежит фикстурой теста
`TestAPackageCarriesModelProfilesForEveryHostItMayMeet`. Попытка вернуть
неверное правило покраснеет на YAML, который они действительно поставляют.
