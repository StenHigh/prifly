# aif-commit: project context

- Commit messages are written in English, Conventional Commits style
  (`feat:`, `fix:`, `docs:`, `refactor:`), whatever `language.ui` says; the
  prompts and confirmations to the developer stay in `language.ui` (Russian).
- The subject explains why the change keeps the contract, not what files moved.
- Never amend; never push — publishing is the owner's own action.
