## MODIFIED Requirements

### Requirement: Контекст и evidence честно описывают свои границы

Fresh-context profile MUST передавать только declared ContextManifest и
различать подтверждённую свежесть, невозможность её подтвердить и нарушение.
Host не добавляет скрытую цель, данные или права; current system, host и user
restrictions применяются поверх pinned package context. Закрытие step требует
declared artifacts, receipts и checker outcome; prose объясняет result, но не
становится evidence. Semantic review допускается лишь с честно названной
моделью или человеком.

Окружение, с которым Run запустит объявленную программу, MUST быть читаемо до
запуска по именам переменных и объявленным местам значений; значения MUST NOT
печататься. Machine-local правка, которая не может достичь уже начатого Run,
MUST называться таковой там, где владелец её делает или ведёт этот Run, а не
оставаться молчаливой.

Отказ, ссылающийся на записанное свидетельство, MUST называть то, что
действительно записано: код завершения программы и границы сохранённого. Если
собственный вывод программы движком не хранится, отказ MUST говорить это, а не
отправлять владельца искать несуществующее.

#### Scenario: Adapter наследует parent transcript

- **WHEN** fresh-context adapter не может исключить скрытую историю родителя
- **THEN** profile не получает qualification свежего context

#### Scenario: Источник объявлен при уже идущем Run

- **WHEN** владелец объявляет источник значения в machine-local настройке, а
  Run, который он ведёт, был запечатан до этого
- **THEN** он узнаёт, что этот Run пойдёт со своим запечатанным окружением, а
  не обнаруживает это по тому, как упала программа

#### Scenario: Программа завершилась ненулевым кодом

- **WHEN** объявленная программа завершилась ненулевым кодом
- **THEN** отказ называет код завершения и то, какое свидетельство записано, а
  какое движком не хранится
