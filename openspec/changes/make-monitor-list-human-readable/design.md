## Context

См. `proposal.md`. Компактная `RunSummary` сейчас читает только RunBrief, тогда как profile `/3` допускает запуск через typed `task` без отдельного RunBrief. Run не хранит связь с Project execution profile, поэтому каталог authority не может надёжно восстановить имя проекта из пути.

## Goals / Non-Goals

**Goals:**

- Показать в общей таблице сохранённое человекочитаемое название задачи и закреплённый title проекта.
- Сохранить distinction между display-данными и техническими identities.

**Non-Goals:**

- Не переписывать исторические Run.
- Не извлекать заголовок из Markdown, URL, пути рабочей папки или внешнего tracker.
- Не строить отдельный каталог названий проектов.

## Decisions

- `RunSummary.Subject` получает fallback только из сохранённого `input_artifacts.task`, если RunBrief отсутствует; JSON читается локально и принимается только непустое строковое `title`. Это использует доказуемый TaskInput вместо синтеза из произвольных bytes. Альтернатива — оставить пустое поле — сохраняет техническую точность, но не решает список.
- Profile получает optional title; `project start` копирует его в versioned поле новых Run. Это единственная надёжная связь с authoring profile в историческом Run. Альтернатива — восстановление через `local.yaml` или путь — не сохраняет identity и ломается при другой структуре каталогов.
- Для legacy Run monitor использует basename authority root только как явно помеченное локальное имя. Это сохраняет полезный список, не объявляя fallback свойством Project execution profile.
- Технические значения остаются под основными названиями, чтобы поиск, прямая ссылка и диагностика не теряли точность.

## Risks / Trade-offs

- [Task имеет другой JSON-формат] → fallback отсутствует; UI явно сообщает, что название не записано.
- [Profile title не задан] → новый Run использует явно помеченное локальное имя; пользователь может добавить title перед следующим запуском.
- [Старые Run] → продолжают использовать существующий RunBrief и fallback authority root без переписывания historical evidence.
