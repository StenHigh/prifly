Владелец должен иметь возможность ответить заранее — тогда останова нет вовсе.

- [x] 3.1 Принять `--runtime-answer ID=JSON` в `project start`: только
      объявленные решения фазы `runtime`, значение проверяется против choices
      или value schema при запуске, а не при запросе.
- [x] 3.2 Запечатать такой ответ в decision sheet записью `answered` с
      источником `actor`.
- [x] 3.3 В `RequestDecision` применять запечатанный ответ раньше автополитики:
      выбор владельца старше умолчания. Записать в ledger `answered`/`actor` с
      ID попытки, которая его получила.
- [x] 3.4 Исключить решения с запечатанным ответом из перечня 1.2: они Run не
      остановят.
