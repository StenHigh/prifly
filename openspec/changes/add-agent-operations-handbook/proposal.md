## Why

Во время Run агент ищет команды и ограничения Pri-Fly в исходном коде, когда runner skill не даёт ответа.
Это расходует контекст и токены; подробный справочник должен давать ответ по задаче, симптому или имени команды.

## What Changes

- Добавить подробный эксплуатационный справочник в `examples/operations/` с коротким индексом задач и симптомов.
- Покрыть все публичные команды, объявленные capabilities, host protocol, авторинг, восстановление и обслуживание.
- Для каждой операции показать условия, команды, значимые поля ответа, варианты, ограничения и следующий шаг.
- Доставлять справочник вместе с runner каждому поддержанному хосту. Для чтения справочника не нужны checkout Core или сеть.
- Сократить основной skill: оставить обязательные ограничения и цикл исполнения; подробности читать по ссылке из индекса.
- Перед каждым новым `project start`, `project continue` и `project recover` проверять и применять обновления binary, установленных workflows и runner.
- При недоступности проверки или конфликте обновления остановить создание нового Run с точной причиной.
- Сохранить настройки проекта, прежние Runs, review digest, exact recognition старых runners и пользовательские файлы.
- Проверять полноту покрытия относительно публичного CLI и `prifly capabilities`. Проверять пригодность справочника на практических задачах без доступа к исходникам.

## Capabilities

### New Capabilities

Нет. Справочник описывает существующие возможности, а не объявляет новую возможность движка.

### Modified Capabilities

- `release-documentation-layout`: эксплуатационный справочник, доставка с runner, покрытие и правила актуализации.
- `cli-protocol`: переход от короткого skill к нужной странице справочника; обязательная проверка обновлений перед новым запуском.

## Impact

Изменяются поставляемый host runner, его установка и обновление, пользовательские справочники и процесс сопровождения документации.
Authority runtime, YAML semantics и сохранённые wire contracts не меняются.
Нормативное владение существующими capabilities не переносится: источниками остаются main specifications и deltas этого change до archive+sync.

Основные места: `cmd/prifly/project.go`, runner upgrade tests, `.agents/skills/prifly-run/`, `.claude/skills/prifly-run/`, `examples/`, `README.md`, `AGENTS.md`.
Текущие команды `update`, `project workflows update` и `project runners update` используются без выдуманных `--check` flags.
Исторические release evidence и schema bundles защищены от изменений.

Карта покрытия и проверенные ограничения: [coverage.md](coverage.md).
Решения о размещении, версиях и обновлении: [design.md](design.md).
