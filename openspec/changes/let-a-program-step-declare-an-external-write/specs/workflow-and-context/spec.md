## MODIFIED Requirements

### Requirement: YAML автор внешней записи сохраняет границу шага

`prifly-step/2` MUST принимать `external_write` и понижать его вместе с
`effects.class: external_write` в StepDefinition v11. Явная фиксация более ранней
версии MUST отказываться. `prifly-step/1` принимает поле только у
шага-программы и понижает его в StepDefinition v14 по требованию «YAML автор
программы сохраняет границу внешней записи». Отсутствие поля MUST оставлять
прежние понижённые байты неизменными.

#### Scenario: Автор объявил внешнюю запись
- **WHEN** ассистируемый YAML-шаг объявляет систему, изменяющие операции и цель
- **THEN** скомпилированный StepDefinition v11 несёт ту же границу без её
  интерпретации

#### Scenario: Граница у шага-программы
- **WHEN** `prifly-step/1` с `executor.operation: process` содержит `external_write`
- **THEN** компиляция понижает его в StepDefinition v14, не удаляя поле молча

#### Scenario: Старый authoring marker
- **WHEN** `prifly-step/1` ассистируемого шага содержит `external_write`
- **THEN** compile отказывает до Run и называет `prifly-step/2`, не удаляя поле
  молча

## ADDED Requirements

### Requirement: YAML автор программы сохраняет границу внешней записи

`prifly-step/1` MUST принимать `external_write` и понижать его вместе с
`effects.class: external_write` в StepDefinition v14. Контракт v14 — программная
ветка: контракт 12 плюс граница внешней записи. Явная фиксация версии ниже 14
при объявленной границе MUST отказываться с названием нужного контракта.
Отсутствие поля MUST оставлять прежние понижённые байты неизменными.
Опубликованные контракты 1–13 MUST NOT меняться.

`prifly-step/2` MUST по-прежнему описывать только ассистируемый шаг. Отказ
программе в `prifly-step/2` MUST называть `prifly-step/1` как маркер, который
несёт и внешнюю запись.

#### Scenario: Программа объявила внешнюю запись
- **WHEN** YAML-шаг `prifly-step/1` с `executor.operation: process` объявляет
  класс внешнего изменения и границу
- **THEN** скомпилированный StepDefinition v14 несёт ту же границу без
  интерпретации

#### Scenario: Прежний шаг-программа
- **WHEN** YAML-шаг `prifly-step/1` не объявляет `external_write`
- **THEN** понижённые байты совпадают с байтами предыдущей сборки

#### Scenario: Явная фиксация старого контракта
- **WHEN** шаг-программа с границей фиксирует `schema_version: "12"`
- **THEN** компиляция отказывает и называет контракт 14
