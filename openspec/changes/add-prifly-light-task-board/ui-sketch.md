Над board — отдельная заметная attention group. На широком экране остальные группы расположены колонками; «План» и «Реализация» можно разделять только при declared mapping, generic показывает «В работе / этап не сопоставлен». Перечень chips динамический: нет fake UI/UX у backend. Цвет дублируется словом и значком. ID вторичны, раскрываются в details, exact Run ссылки доступны у каждого current Run.

Счётчики относятся ко всему выбранному набору, колонки содержат только текущую страницу. Каждая колонка подписывает «на странице N, всего M» либо «итог неизвестен, индекс строится». Одна карточка появляется в одной группе; если у неё есть работа сразу в нескольких фазах, перечисляются все active phases, а группа выбирается по документированному приоритету. Attention не делает остальные ветви невидимыми.

## Task details

Отдельный экран с breadcrumb «К доске», сохранёнными filters/page/scroll. Заголовок, проект, queue state и понятная причина; далее current Runs/branches с собственными status/outcome, текущий candidate/round либо «не установлен». Переключение текущего и historical review не смешивает candidate scopes.

Таблица review: lens → проверка → gate/приёмка → freshness → findings. По действию «Источник» — producer identities, exact report/gate/request/candidate refs, mapping digest, source cut и lazy raw preview. Старое ревью подписано «Предыдущий candidate / историческое», с недоступностью bytes отдельно. История Runs постраничная; partial source остаётся partial после успешного continue.

Переход в full monitor строится по настроенному base URL и exact source/run: текущий формат full monitor — hash `#source=…&run=…&tab=facts` через URLSearchParams. Путь/query full base сохраняются. Открытие новой вкладки сохраняет Light tab и контекст; обычный Back также восстанавливает выбранный фильтр. Core не добавляет open redirect через пользовательский return URL и не меняет router полного monitor.

## Mobile and keyboard

На 360–430 px группы идут вертикально, filters складываются в подписанную панель, counters переносятся; page navigation остаётся видимой. Нет обязательного горизонтального drag. Карточки используют настоящие links/buttons, Tab идёт от filters к pagination и карточкам. Видимый focus, Enter открывает details, Back восстанавливает страницу и focus. Нет keyboard trap, обновление не перемещает focus/scroll. Контраст и light/dark/system theme проверяются actual browser на desktop и mobile viewport.

## Loading, empty, error

- Первая загрузка: skeleton, «Собираем индекс», source coverage; пустота до загрузки не объявляется отсутствием задач.
- Пустой источник: «В этом проекте ещё нет задач и Runs». Пустой filter: «По этим условиям ничего не найдено», действие сброса filters.
- Один source недоступен: banner и его last-success time, healthy проекты продолжают работать; известные прежние карточки stale, не исчезают как completed.
- Expired page: сохранённые filters и понятное действие «Обновить страницу данных»; не склеиваем старую и новую страницу.
- Poll: last-success freshness обновляется без скачков layout; error не заменяет last good body пустым списком.
- Unknown review: «Нет данных» с причиной; disabled/not-applicable отличаются от waiting, defect, unavailable и passed.
