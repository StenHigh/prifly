## Why

При нескольких Run таблица не даёт быстрого обзора одновременно работающих
ветвей, ожиданий и остановленной приёмки. Issue #4 требует дополнительную
доску по записанным фактам исполнения с доступной историей продолжений.

## What Changes

- Дополнительный вид доски с категориями работы, ожидания ответа/сигнала,
  ожидания ресурса, остановленного/неопределённого исполнения, terminal и
  явно неизвестного состояния.
- Компактная согласованная проекция текущих стадий, активных Attempts,
  причин и следующего действия; несколько parallel-ветвей видны вместе.
- Ссылки на точные исходные/производные Run по записанному provenance и
  переходы к существующим подробностям с сохранением навигации.
- Тесты проекции, HTTP/UI и живая browser-проверка, включая более 200 Run.

## Capabilities

### New Capabilities

Нет: доска расширяет существующий локальный monitor.

### Modified Capabilities

- `local-run-monitor`: дополнительная доска по сохранённому состоянию Run.

## Impact

Изменяются local monitor, его внутренние read projections, tests и инструкции
пользователя. Исполнение workflow, публичные versioned state/read schemas и
YAML authoring не меняются. Это продуктовая UI-возможность, а не изменение
процесса репозитория. Ownership нормативных источников остаётся у
`openspec/specs/local-run-monitor/spec.md`; новых task identity или queue нет.
