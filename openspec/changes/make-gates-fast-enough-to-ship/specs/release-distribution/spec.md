## ADDED Requirements

### Requirement: Проверки делятся на повседневные и предрелизные
Каждый push SHALL проходить быстрый набор: все тесты без race-детектора и все статические проверки обеих выпускаемых платформ. Race-детектор и полный e2e SHALL выполняться предрелизной квалификацией на конкретном коммите. Release tag MUST ставиться только на коммит, для которого успешны и быстрый набор, и квалификация; инструмент выпуска MUST отказывать с названием недостающей проверки. Сокращение времени MUST NOT убирать проверку из обоих уровней: каждая проверка, существовавшая до разделения, выполняется хотя бы в одном из них, а перед релизом — во всех.

#### Scenario: Обычный push
- **WHEN** разработчик отправляет коммит в любую ветку
- **THEN** GitHub запускает быстрый набор параллельными задачами, без race-детектора и полного e2e

#### Scenario: Выпуск без квалификации
- **WHEN** владелец просит выпустить тег на коммит без успешной квалификации
- **THEN** инструмент выпуска отказывает и называет, какая проверка не пройдена или не запускалась

#### Scenario: Проверка не потерялась
- **WHEN** сравнивают список проверок до и после разделения
- **THEN** каждая прежняя проверка есть в быстром наборе или в квалификации, и квалификация перед релизом выполняет все
