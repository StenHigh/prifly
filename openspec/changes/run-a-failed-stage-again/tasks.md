## 1. Стадия не убивает Run

- [ ] 1.1 `internal/flow`, `internal/runtime`: стадия объявляет предел повторов технической неудачи; в его пределах создаётся новая попытка того же StepInstance, вне — прежнее поведение. Проверка: тест — программа, падающая один раз и проходящая со второй попытки, доводит Run до конца; предел исчерпан — Run падает как прежде; `go test ./internal/runtime -run 'Driver|Retry'`.
- [ ] 1.2 Предметный вердикт повтором не отменяется. Проверка: тест — стадия, вернувшая `fail`, не повторяется, сколько бы повторов ни было объявлено.

## 2. Упавший Run не выбрасывает работу

- [ ] 2.1 `run fork` принимает точку входа: новый Run начинается с названной стадии, наследуя запечатанные выходы предыдущих по ref и digest. Проверка: тест — Run, упавший на программной стадии, форкается с неё; стадии до неё не исполняются, их выходы те же по digest; исходный Run не изменился ни в одном байте.
- [ ] 2.2 Провенанс называет унаследованное: читатель видит, какие стадии не исполнялись в этом Run и от какого Run взяты их выходы. Проверка: тест на чтение нового Run.
- [ ] 2.3 Права не наследуются: claim берётся заново, approvals и grants исходного Run не переходят. Проверка: тест — форк с точкой входа требует claim и отказывает, если рабочая копия занята.
