## ADDED Requirements

### Requirement: Узел объявляет исход каждого вердикта, который шаг может вернуть
Запечатывание MUST отвергать шаговый узел, у которого объявлен маршрут не для
каждого вердикта, достижимого для этого шага, если автор явно не объявил, что
вердикт на этом узле невозможен. Отказ MUST называть узел, вердикт и действие,
которым это исправляется.

Требование MUST относиться только к той версии контракта ревизии, которая
вводит явное объявление невозможности, и MUST NOT применяться к ревизиям,
запечатанным раньше: у них нет способа объявить невозможность, а их байты
перекомпилируются при каждой загрузке Run. Само объявление MUST быть допустимо
только в этой версии, чтобы сборка, которая его не знает, отказывала по версии
контракта, а не по неизвестному полю.

Отсутствие объявления MUST NOT толковаться как «вердикт невозможен»: разница
между решением автора и его невнимательностью MUST быть видна в самом
объявлении. Принятие отчёта с вердиктом, для которого маршрут не объявлен, и
последующий отказ при маршрутизации MUST NOT быть нормальным путём для новой
ревизии; для ранее запечатанной он остаётся прежним поведением, и принятый
отчёт MUST сохраняться.

#### Scenario: Автор не объявил отрицательный исход
- **WHEN** узел ревизии этой версии объявляет только успешный маршрут, а шаг
  способен вернуть вердикт, требующий доработки
- **THEN** запечатывание отказывает и называет недостающий вердикт, вместо того
  чтобы принять отчёт и уронить прогон на маршрутизации

#### Scenario: Автор решил, что вердикт невозможен
- **WHEN** он объявляет это явно для конкретного узла
- **THEN** запечатывание проходит, и объявление остаётся читаемым в YAML без
  обращения к коду

#### Scenario: Прогон, запечатанный прежней версией контракта
- **WHEN** сборка загружает Run, чей граф оставляет вердикт без маршрута и не
  несёт объявления невозможности
- **THEN** граф компилируется по прежнему правилу и прогон продолжается; такой
  вердикт, если он случится, остаётся ошибкой маршрутизации в рантайме, а
  принятый до неё отчёт не теряется
