## Context

См. proposal.md — Why. `project local set --env NAME=VALUE`
(`cmd/prifly/project_local_execution.go`) пишет пары в `environment`
машинного `local.yaml`; runtime передаёт их программе поверх чистого
окружения. Другой формы нет: значение обязано быть литералом в файле.

## Goals / Non-Goals

**Goals:**
- Секрет не появляется ни в одном файле репозитория и ни в одном выводе.
- Отсутствие секрета — отказ до запуска программы, названный по имени
  переменной, а не падение программы на аутентификации через минуту.

**Non-Goals:**
- Хранилище секретов, интеграции с менеджерами секретов, расшифровка.
- Передача секретов ассистируемому шагу: у него нет объявленного окружения,
  и это отдельный разговор.
- Наследование всего окружения вызывающего: только названные переменные.

## Decisions

1. **Две формы источника: переменная окружения вызывающего и файл.**
   Переменная покрывает CI и запуск руками, файл покрывает `.env`-подобные
   хранилища проекта. Обе называются в `local.yaml` рядом с литералами.
2. **Разрешение — в момент запуска программы**, не при чтении конфигурации:
   иначе значение пришлось бы держать в памяти между командами и печатать в
   `--prepare`.
3. **Отсутствие источника — отказ до запуска**, с именем переменной и местом.
   Пустое значение считается отсутствием: пустой пароль — не пароль.
4. **Значение не участвует в digest'е конфигурации**, но участвует **факт**
   объявления источника: смена источника меняет digest, смена значения — нет.
   Иначе владелец не увидел бы, что программа стала брать секрет из другого
   места.
5. **Файл читается целиком как значение** (с обрезкой конечного перевода
   строки), а не разбирается как `.env`: разбор чужого формата — это догадка
   о чужом синтаксисе, и она ошибётся на кавычках и комментариях.

## Risks / Trade-offs

- [Значение всё же попадёт в вывод программы] → это уже её ответственность;
  движок не печатает его сам и не кладёт в артефакты.
- [Источник изменился между `--prepare` и `start`] → digest конфигурации
  меняется только при смене источника; значение проверяется при запуске, и
  отказ называет переменную.
- [Файл с секретом читается процессом движка] → так же, как читается
  `local.yaml` сегодня; права на файл остаются делом машины.
