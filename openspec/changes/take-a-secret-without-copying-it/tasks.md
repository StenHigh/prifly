## 2. Запуск программы

- [x] 2.1a Разбор файла с ключом ограничен объявленной грамматикой: первая строка `KEY=`, значение — остаток строки дословно, `#` в начале строки пропускается, значение в кавычках — именованный отказ. Проверка: тест на каждую из четырёх форм строки.
- [x] 2.1 `internal/runtime`: источник разрешается перед запуском программы; отсутствующий или пустой — именованный отказ до старта с именем переменной и местом. Проверка: тест — программа с отсутствующим источником не запускается, отказ называет переменную; `go test ./internal/runtime -run 'Process|Execution'`.
- [x] 2.2 Значение не печатается нигде: `--prepare`, `session task`, диагностики, журнал. Проверка: тест — вывод содержит имя и не содержит значения.
