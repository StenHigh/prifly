## ADDED Requirements

### Requirement: Объявленный эффект шага — читаемый факт Run

Для каждой шаговой стадии Run authority MUST отвечать при чтении Run, что
объявил её запечатанный шаг: класс эффекта и `retry_class`, а при
`external_write` — ещё и границу (систему, изменяющие операции и цель). Ответ
MUST браться из определения шага, запечатанного в Run, а не из текущего пакета.
Authority MUST NOT представлять этот ответ наблюдением того, что шаг сделал:
это то, что шаг объявил.

#### Scenario: Читатель ищет границу внешней записи
- **WHEN** Run исполнил шаг-программу с `effects.class: external_write` и
  границей
- **THEN** чтение Run называет для этой стадии `external_write`, её
  `retry_class`, систему, операции и цель, не требуя разбирать байты
  определений

#### Scenario: Пакет обновлён после Run
- **WHEN** новая редакция пакета изменила эффект шага, а Run исполнялся
  прежней
- **THEN** чтение Run называет эффект, запечатанный в этом Run
