## Why

В списке Run колонка «Шаги / попытки» показывает `4 / 4` и ниже «3 попыток завершено». Дробь похожа на прогресс «четыре из четырёх», хотя это два разных количества: созданные StepInstance и Attempt; третье число — учтённые Attempt. По этой строке трудно понять, что один исполнитель ещё ожидается.

## What Changes

- Заменить безымянную дробь отдельными подписями для фактически созданных экземпляров шагов и попыток исполнения. Не выдавать эти числа за долю выполненного Workflow или количество всех узлов закреплённой схемы.
- Показывать состояние попыток понятной строкой: сколько учтено, сколько остаётся незавершёнными и, если известно, сколько из них ожидает хоста. Отличать завершение попытки от успешного verdict и outcome Run.
- Дать краткое доступное пояснение разницы между StepInstance и Attempt, включая повторные попытки и вложенные/повторяющиеся шаги. Сохранить компактность таблицы и читаемость на узком экране.
- Использовать существующие поля read-only RunSummary. Сохранённые Runs, JSON-контракты и подсчёт authority не менять.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `local-run-monitor`: список Run ясно различает созданные шаги, все попытки и учтённые попытки без ложного прогресс-индикатора.

## Impact

Только локальный интерфейс монитора и его UI-проверки; возможно текстовая справка в интерфейсе. Product runtime, API, схемы, история Run и другие активные changes не меняются.
