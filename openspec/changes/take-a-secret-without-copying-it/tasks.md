## 1. Форма и её чтение

- [ ] 1.1 `cmd/prifly/project_local_execution.go`: `environment` допускает запись с источником (переменная окружения вызывающего или файл) рядом с литералом; `project local set` получает флаги для обеих форм. Проверка: тест — обе формы читаются и записываются, литерал не сломан; `go test ./cmd/prifly -run 'Local'`.
- [ ] 1.2 Digest конфигурации меняется при смене источника и не меняется при смене значения. Проверка: тест на два `--prepare` с разным значением одной и той же переменной-источника.

## 2. Запуск программы

- [ ] 2.1 `internal/runtime`: источник разрешается перед запуском программы; отсутствующий или пустой — именованный отказ до старта с именем переменной и местом. Проверка: тест — программа с отсутствующим источником не запускается, отказ называет переменную; `go test ./internal/runtime -run 'Process|Execution'`.
- [ ] 2.2 Значение не печатается нигде: `--prepare`, `session task`, диагностики, журнал. Проверка: тест — вывод содержит имя и не содержит значения.
