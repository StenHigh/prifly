# Evidence — harden-authority-reliability-and-performance

Все числа сняты на одной машине, одним прогоном инструментов, 2026-09-04.

## Где измерялось

- Аппаратура: Apple M1, 8 логических ядер.
- ОС: Darwin arm64 (Darwin 25.5.0).
- Go: go version go1.27.0 darwin/arm64.
- SQLite (CLI той же линии, что и слинкованная): 3.45.1.
- Durability: WAL, `synchronous=FULL`, `foreign_keys=ON`, `_busy_timeout=3s`. FULL сохранён намеренно — см. задачу 4.4.
- Команда: `go test ./internal/... -run '^$' -bench . -benchtime 3x -count=1`.

## Benchmarks

| Benchmark | Что измеряет | Результат |
|---|---|---|
| `BenchmarkOpenStore10MB` | Открытие authority с ~10 МБ истории (1200 событий по 8 КБ), включая инкрементальную проверку | 14–19 мс/оп |
| `BenchmarkVerifyStore10MB` | Полная проверка той же базы — то, что делал каждый open до этого change (и что теперь делает `doctor`) | 3.3 мс/оп на прогретом кэше |
| `BenchmarkLoad1000Invocations` | Чтение Run с 1000 invocations (~4 МБ состояния) | 42 мс/оп (97 МБ/с) |
| `BenchmarkTiming1000Nodes` | Расчёт timing-дерева на 1000 узлов | 0.23–0.38 мс/оп |
| `BenchmarkRunStatus` | `View` завершённого Run: чтение, timing и восстановление истории переходов из журнала | 1.0–1.1 мс/оп |
| `BenchmarkAdmit` | Допуск одной попытки: команда, её транзакция и все проверки до старта работы | 53–60 мс/оп |
| `BenchmarkPublish` | Одна публикация события работником | 12–15 мс/оп |

`BenchmarkAdmit` и `BenchmarkPublish` включают полный fsync-цикл SQLite при
`synchronous=FULL`: это стоимость durable коммита на этой машине, а не работа
движка. Их значение здесь — база для сравнения, а не цель.

## Чего эти числа не показывают

- Машина одна, прогон один, `-benchtime 3x`: это порядки величин, а не
  статистика. Для регрессионного сравнения нужен тот же хост и тот же профиль
  durability.
- `BenchmarkLoad1000Invocations` меряет Run, какого в продукте пока нет: он
  показывает, где стоимость чтения становится сериализацией JSON (декод 21.7 мс,
  повторный разбор верхнего уровня 8 мс, а на записи `canonicalState` 111 мс, из
  которых 92 мс — канонизация).
- Ни один из бенчмарков не измеряет работу воркера: это стоимость авторитета
  вокруг неё.
