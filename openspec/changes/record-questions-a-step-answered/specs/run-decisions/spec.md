## ADDED Requirements

### Requirement: Шаг сообщает вопросы, на которые ответил
В Run, запечатанном на версии состояния, которая это записывает, отчёт каждой assisted-сессии MUST нести список вопросов, возникших у шага за Attempt, с ответом и основанием каждого ответа: объявленное решение Run, названный вход шага, переданные инструкции, человек в сессии или собственное суждение исполнителя. Пустой список SHALL означать заявление «вопросов не было», а отсутствие списка MUST отклонять отчёт с кодом, называющим, что прислать. Основание «решение» MUST ссылаться на решение из каталога Run, основание «вход» — на вход шага. Запись MUST храниться отдельно от журнала решений, MUST NOT становиться DecisionRecord, Approval или доказательством присутствия человека и MUST оставаться доступной для чтения после завершения Run.

#### Scenario: Навык спросил в чате, агент ответил по handoff
- **WHEN** навык шага задал вопрос native-диалогом, и агент ответил на него сведениями из входа `handoff`
- **THEN** Attempt хранит вопрос, ответ и основание «вход `handoff`», а журнал решений не получает новой записи

#### Scenario: Ответ из запечатанного решения
- **WHEN** агент ответил на вопрос навыка ответом объявленного решения из `decision_context`
- **THEN** запись называет это решение по id, и отчёт с id, которого нет в каталоге Run, отклоняется

#### Scenario: Вопросов не было
- **WHEN** шаг отработал без вопросов
- **THEN** отчёт несёт пустой список, и чтение Run говорит «вопросов не было», а не «не записано»

#### Scenario: Run, запечатанный раньше
- **WHEN** отчёт приходит для Run на более ранней версии состояния
- **THEN** список не требуется, а чтение говорит, что вопросы в этом Run не записывались
