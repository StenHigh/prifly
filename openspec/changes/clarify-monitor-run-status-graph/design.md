## Context

Монитор получает только сохранённый снимок Run и уже строит SVG без внешней
зависимости. `ready`, `pending` и `running` — разные записанные состояния,
но их короткие подписи не объясняют переход между созданием шага, передачей
Attempt и запуском процесса.

## Goals / Non-Goals

**Goals:**

- Передать точный смысл записанных состояний в русской UI.
- Сделать выбранный путь в динамическом графе первым зрительным слоем, не
  скрывая исключённые ветви.
- Сократить пересечения за счёт отдельных каналов основного, return и
  terminal-путей без изменения модели Run.
- Дать выбранному узлу компактную карточку отношений и записанных фактов.

**Non-Goals:**

- Не менять runtime, JSON, API и сохранённые Run.
- Не встраивать статический генератор Archify или новую библиотеку графов.
- Не скрывать топологию закреплённого Workflow.

## Decisions

- Оставить технические статусы в данных и заменить только читательские
  подписи. Это сохраняет совместимость со старыми Run и точно отделяет
  `ready` от «завершено».
- Построить слои из закреплённого workflow: фактический маршрут становится
  центральной горизонтальной spine, достижимые продолжения размещаются рядом,
  а terminal и return-маршруты — в отдельных нижних каналах. Это переносит
  layout-принципы Archify, а не его статический renderer или зависимость.
- Классифицировать каждый узел только по сохранённым Activation, Attempt,
  маршрутизации и outcome: выполнен, текущий, достижим, исключён с причиной
  либо неизвестен. Альтернатива — прятать исключённые узлы — отвергнута по
  требованию наблюдаемости.
- Развернуть существующий inspector в карточку выбранного узла. Входящие и
  исходящие рёбра берутся из закреплённого определения, а статусы, причины и
  данные — только из сохранённого Run. Альтернатива — отдельный sidecar или
  новый API — не нужна.

## Risks / Trade-offs

- [Очень плотный циклический граф остаётся прокручиваемым] → сохранить
  существующий SVG-контейнер, вынести return-дуги в отдельный канал и покрыть
  маршрутизацию unit-проверкой.
- [Для части отсутствующих исполнений причина не записана] → показывать
  «Причина не записана», а не выводить её из формы графа.
- [Сообщение чата может появиться раньше следующего снимка] → подписи
  описывают только записанный факт, не утверждая состояние живого агента.

## Migration Plan

1. Обновить только JS/CSS монитора и его unit-проверку.
2. Проверить `cmd/prifly/monitor_ui_test.cjs` и e2e монитора.
3. Откатить изменённые статические ресурсы вместе; данные Run не требуют
   миграции.
