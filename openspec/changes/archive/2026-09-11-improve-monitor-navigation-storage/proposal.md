## Why

Длинный список Run отодвигает подробности за пределы экрана. Монитор не показывает объём authority, поэтому рост истории и артефактов незаметно расходует диск.

## What Changes

- Отдельный экран Run с возвратом к списку без потери фильтров, страницы и позиции.
- Фоновый подсчёт занятого места всеми найденными хранилищами и каждым отдельно, с временем измерения, ошибками и доступным местом на соответствующем диске.
- Управление удалением окончательно завершённых Run и очисткой через явное подтверждение. Активные, ожидающие и неопределённые исполнения защищены на сервере.
- По решению владельца массовая очистка охватывает завершённые Run и неиспользуемые артефакты, с эксклюзивным доступом к authority. Импортированные независимые объекты, общие данные и audit/receipts сохраняются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `local-run-monitor`: навигация, объём хранилищ и явно разрешённые операции обслуживания.
- `control-security-ux`: исключение для защищённого подтверждённого обслуживания локального монитора.
- `runtime-resources`: безопасное удаление завершённой истории, сохранение общих данных и audit/dedup boundary.

## Impact

Изменение продукта: cmd/prifly monitor, runtime/local storage, browser UI и их проверки. Владение нормативными источниками не меняется. Новые зависимости не нужны. Старые опубликованные контракты и release evidence не переписываются.
