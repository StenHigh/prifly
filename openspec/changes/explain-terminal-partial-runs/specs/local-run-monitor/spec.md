## ADDED Requirements

### Requirement: Терминальный частичный итог объясняет завершение Run

В подробностях терминального Run монитор SHALL явно отличать завершение работы внутри этого Run от отсутствия записанной текущей активности. Для `outcome: partial` он SHALL показывать смысл частичного итога и записанную причину завершения, если её можно однозначно связать с фактическим маршрутом, с навигацией к соответствующим сохранённым данным. Он MUST NOT выводить причину, обязательное следующее действие или активность исполнителя из одного только названия стадии, произвольного текста артефакта либо внешнего чата. Если доказанной причины нет, монитор SHALL обозначать её как неустановленную. Проектная рекомендация, если она показана, SHALL быть помечена как записанная рекомендация, а не состояние или команда Pri-Fly.

#### Scenario: Частичный Run завершился после блокирующего результата
- **WHEN** Run имеет терминальные `status: completed`, `outcome: partial`, а его фактический маршрут и принятый результат однозначно связывают завершение с блокирующим вердиктом и сохранённым артефактом
- **THEN** обзор сообщает, что внутри этого Run сейчас ничего не исполняется и он сам не продолжится, называет записанную причину и открывает связанный результат или артефакт

#### Scenario: Причину нельзя доказать по сохранённым данным
- **WHEN** терминальный Run имеет `outcome: partial`, но завершающий маршрут или относящийся к нему результат неоднозначен либо недоступен
- **THEN** обзор показывает статус и известные факты, прямо отмечает неизвестную причину и не приписывает её произвольно выбранному шагу

#### Scenario: Работа в чате не принадлежит завершённому Run
- **WHEN** после завершения частичного Run хост продолжает работу вне его записанных Attempt
- **THEN** монитор не обозначает этот Run как работающий или ожидающий агента и не выдаёт внешнюю работу за его автоматическое продолжение

#### Scenario: Не частичный терминальный исход
- **WHEN** Run завершён с другим `outcome` либо техническим отказом
- **THEN** монитор показывает его собственные статус и причину без шаблонного объяснения для `partial`
