## Why

Холодный заход на 0.13.33 (сессия без памяти о Pri-Fly, отдельная машина,
сырьё прислано дословно) прошёл подключение клона — и уткнулся в тот же тупик
на шаг позже. `project init --repository . --host claude-code --state-root DIR`
в клоне, чей профиль **уже объявляет** `claude-code` и чей раннер лежит в
дереве, отказывает:

```
project_profile_conflict: use project runners add --host NAME to attach a host to an existing profile
```

Подсказка ведёт в тупик мягкий, а не громкий: `project runners add --host
claude-code` для уже присутствующего раннера ничего не делает и возвращает
`added_hosts: []` с кодом 0. Разработчик получает успех, но не получает того,
за чем пришёл, — local configuration и authority по-прежнему нет. Выход —
`project init` **без** `--host`, и об этом не говорит никто.

Причина в коде одна строка: при существующем профиле отказывается **любой**
`--host`, хотя отказ осмыслен только для хоста, которого профиль не объявляет.
Хост, названный ради «я работаю отсюда», — это не попытка присоединить второй.

Рядом, из того же отчёта: квитанция `project local set` говорит о себе не то,
что лежит в файле. `environment` она печатает из `local.yaml` целиком, а
`allowed_executables` — только то, что передали этим вызовом. После
`project local set --env-from …` владелец видит `"allowed_executables":{}`
при живом `executables: {shell: /bin/bash}` в файле. Данные целы, но
квитанция читается как «разрешения исчезли».

Изменение затрагивает product runtime и вывод CLI; ownership источников не
меняется.

## What Changes

- `project init` при существующем профиле принимает `--host`, если каждый
  названный хост уже объявлен профилем: создаёт недостающую local
  configuration и authority, как это делает форма без `--host`, ничего не
  переписывая и называя `missing_hosts`. Отказ `project_profile_conflict`
  остаётся ровно для хоста, которого профиль не объявляет, — там подсказка
  про `runners add` верна.
- Квитанция `project local set` печатает разрешённые программы так же, как
  печатает окружение: из файла, а не из аргументов этого вызова.
