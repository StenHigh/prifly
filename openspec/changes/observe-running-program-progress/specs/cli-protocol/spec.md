## ADDED Requirements

### Requirement: Прогресс работающей Attempt доступен только для чтения

Новая versioned CLI/read projection SHALL показывать для program Attempt состояние `reported|not_reported|stale|unavailable`, последнюю фазу, наблюдённое время и известные счётчики. Отсутствующие значения MUST оставаться отсутствующими, а не нулём; счётчик `current/total` MUST показываться только при положительном `total` и `0 <= current <= total`. Чтение не запускает программу, не продлевает lease и не меняет Run. Прежние версии публичных ответов сохраняют форму и значение.

#### Scenario: Прогресс виден другому клиенту
- **WHEN** tests-worker сообщает `product` и `4200/6994`, пока Attempt исполняется
- **THEN** отдельный read-only CLI клиент получает эту фазу и счётчик с временем наблюдения без вывода `pass`

#### Scenario: Наблюдение недоступно
- **WHEN** программа не сообщила прогресс либо сведения потеряны после рестарта
- **THEN** ответ различает `not_reported` и `unavailable`, не предлагает угаданный процент

### Requirement: Разрешённый вывод программы читается ограниченными фрагментами

Новая versioned read-only CLI projection SHALL выдавать live-tail stdout и stderr только для program Attempt, чья pinned StepDefinition явно разрешает раскрытие. Потоки MUST оставаться различимыми. Ответ SHALL содержать Attempt identity, границы/порядок фрагмента, время наблюдения и признаки потери, усечения либо недоступности; пропущенные bytes MUST NOT выглядеть непрерывным выводом. Для шага без opt-in содержимое и его фрагменты MUST отсутствовать, а не раскрываться через другой endpoint. Чтение MUST применять существующую проверку доступа к Run, не запускать процесс и не изменять Run; старые версии ответов сохраняют форму.

#### Scenario: Читатель отстал от кольцевого буфера
- **WHEN** opt-in программа вывела больше, чем помещается в tail, пока клиент не опрашивал её
- **THEN** следующий ответ содержит доступный фрагмент и явный признак пропуска, не выдавая его за полный transcript

#### Scenario: Opt-in отсутствует
- **WHEN** CLI читает работающую Attempt шага без разрешения на раскрытие
- **THEN** содержимое stdout/stderr не возвращается даже при наличии диагностического вывода у driver
