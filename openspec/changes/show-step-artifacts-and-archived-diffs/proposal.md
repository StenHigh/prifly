## Why

Оператору приходится искать входы и выходы шага в служебных данных. Историческое сравнение коммитов должно открываться после удаления рабочего дерева или потери доступа к Git.

## What Changes

- Показать полученные артефакты и принятые выходы выбранной попытки рядом с предпросмотром.
- Читать документы, диапазоны коммитов, merge request и сохранённые diff из authority. Для остальных артефактов сохранить общий просмотр.
- Сохранять diff до принятия результатов шагов с объявленными выходами сравнения.

## Capabilities

### Modified Capabilities

- `local-run-monitor` показывает содержимое разных видов артефактов.
- `aif-classic-workflow` объявляет сохранение diff для шагов, которые создают implementation.

## Impact

Локальный монитор, приём отчёта assisted шага, проверка при освобождении дерева и пакет aif-classic проекта. Существующий формат Run и StepResult пригоден для чтения.
