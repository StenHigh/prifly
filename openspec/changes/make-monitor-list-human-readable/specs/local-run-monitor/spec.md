## MODIFIED Requirements

### Requirement: История имеет поиск и постраничную навигацию без общего предела
Монитор SHALL предоставлять поиск по задаче, Run и сценарию, фильтры проекта, состояния, исполнителя и периода, сортировку и постраничную загрузку. Число Run больше 200 MUST NOT приводить к отказу либо скрытому обрезанию. Прямая ссылка SHALL восстанавливать выбранные источник, Run и узел. Фильтрация применяется ко всей доступной истории, а неполный индекс отмечается. Главная строка списка SHALL показывать сохранённый заголовок RunBrief либо, при отсутствии RunBrief, сохранённый `title` входного TaskInput; при отсутствии обоих интерфейс MUST явно показывать отсутствие названия. Главная строка проекта SHALL показывать title Project execution profile, закреплённый в Run; если такой title не записан, монитор MUST показать basename authority root как fallback, помеченный как локальное имя. Идентификаторы Run и проекта, workflow и полный путь MUST оставаться доступными вторичными данными; монитор не создаёт названия из незафиксированных данных и не меняет сохранённые Run.

#### Scenario: История больше одной страницы
- **WHEN** в хранилище есть более 200 Run и искомый запуск не находится на первой странице
- **THEN** он доступен поиском и переходом по страницам без обхода лимитов полного telemetry scan

#### Scenario: Run с входом TaskInput без RunBrief
- **WHEN** Run хранит `task` с непустым `title`, но отдельный RunBrief отсутствует
- **THEN** список показывает этот title как задачу и сохраняет технический Run ID вторичной строкой

#### Scenario: Название задачи не записано
- **WHEN** Run не содержит ни RunBrief, ни `task.title`
- **THEN** список явно обозначает отсутствие названия и не выводит произвольный идентификатор как название задачи

#### Scenario: Project title закреплён в Run
- **WHEN** новый Run начат через Project execution profile с title
- **THEN** список показывает этот title как проект, а project identity, workflow и полный путь оставляет вторичными данными

#### Scenario: Старый Run без project title
- **WHEN** Run не содержит закреплённого title Project execution profile
- **THEN** список показывает basename authority root с пометкой «локальное имя», не выдавая его за сохранённый title
