## Context

См. proposal.md — Why. `Next` (`internal/runtime/engine.go:596`) отдаёт
`NextView` с `action`, `work_id`, `stage_id` и `safe_next_actions`;
`nextKind` возвращает `stage` для готовой стадии, не заглядывая в её шаг.
`run next`, `run explain` и `run drive --next` возвращают один и тот же
документ (`cmd/prifly/main.go:969`), и только `drive` при этом ведёт Run.
Bundle'ы /30 и старше закрывают форму NextView (`additionalProperties: false`).

## Goals / Non-Goals

**Goals:**
- Хост выбирает способ вызова драйвера, зная род работы, а не по опыту.
- Чтение остаётся чтением: род программы называется без её запуска.

**Non-Goals:**
- Флаг `--no-exec` у `run drive`: команда «не делай того, зачем позвали» уже
  есть и называется `run next`.
- Новое значение `action`: род работы — не действие хоста, а свойство стадии;
  смешав их, мы заставили бы каждого читателя `action` учить новые слова.
- Переименование `idle` (отдельное решение владельца, запись в справочнике уже
  есть).

## Decisions

1. **Отдельное необязательное поле рядом с `stage_id`**, значения
   `assisted_session`, `program`, `control`. Отсутствие поля означает «эта
   сборка не знает», а не «управляющая стадия»: догадка здесь дороже молчания.
2. **Род выводится из закреплённого определения шага** (`p.Steps[stageID]`,
   `Executor.AdapterRef`/`Operation`): assisted-адаптер с операцией `session`
   — `assisted_session`; операция `process` — `program`; стадия, которая не
   шаг, — `control`. Ни имя стадии, ни текст инструкции в расчёт не идут.
3. **Новая версия семейства read-контрактов (31)**, как у 29 и 30: bundle
   закрывает форму, поэтому поле не добавляется в опубликованный /30. Новые
   Run пишутся под /31, сохранённые читаются прежними контрактами.
4. **Только при `action: stage`.** У `waiting_decision`, `uncertain`,
   `terminal` и прочих род работы не определён, и пустое поле там честнее
   выдуманного.

## Risks / Trade-offs

- [План стадии недоступен при чтении (повреждённое состояние, чужая сборка)] →
  поле опускается; чтение не отказывает из-за справочного поля.
- [Хост читает род и всё равно гонит программу в харнесе] → это его выбор;
  движок называет факт, дисциплину он не заменяет.
